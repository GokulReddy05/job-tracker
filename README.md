# JobTrack

A modern job application tracking web application built with React.

JobTrack helps users discover job opportunities, view job details, apply for jobs, and keep track of their applications in one place.

## 🚀 Features

- Browse available jobs
- Search jobs by company, role, or location
- View detailed job information
- Apply for jobs
- Prevent duplicate applications
- Track application status
- Dashboard with application statistics
- Recent application overview
- Persistent applications using localStorage
- Responsive modern UI
- Client-side routing with React Router

## 🛠️ Tech Stack

- React
- JavaScript
- Tailwind CSS
- React Router
- Lucide React
- Vite
- LocalStorage
